# نصب برای دوستان

این راهنما برای کسی نوشته شده که می‌خواهد **حلقه** را روی گوشی خودش نصب کند. نیازی به دانش فنی نیست.

## ۱. پیش‌نیاز

- گوشی **اندروید ۷ (API 24) یا بالاتر**.
- این برنامه روی گوگل‌پلی **نیست**؛ فایل APK را مستقیم نصب می‌کنی.

## ۲. دانلود

از صفحهٔ **Releases** همین مخزن، آخرین فایل `halgheh-vX.Y.Z.apk` را دانلود کن.

## ۳. نصب

1. فایل دانلودشده را در مرورگر یا فایل‌منیجر باز کن.
2. اندروید می‌پرسد «نصب از این منبع مجاز نیست». بزن **تنظیمات** و برای همان مرورگر (یا فایل‌منیجر) گزینهٔ **اجازه از این منبع** را روشن کن و برگرد.
3. **نصب** را بزن. اگر Play Protect هشدار داد، چون برنامه امضای گوگل‌پلی ندارد طبیعی است؛ «نصب کن» را انتخاب کن.
4. **باز کردن** — دفترچه از خالی شروع می‌شود. هیچ حساب یا ثبت‌نامی لازم نیست.

## ۴. از کجا شروع کنم؟

| می‌خواهم… | کجا |
|---|---|
| آدم اضافه کنم | تب **افراد** → دکمهٔ **افزودن** (یا از دفترچه تلفن: آیکن گوشی) |
| کارهایی که کسی از من خواسته | تب **کارها** → افزودن → «چه کسی خواسته» |
| ببینم چه کسی چه کاری بلد است | **افراد** → آیکن جعبه‌ابزار |
| تولدها | **بیشتر** → تولدها |
| عکس/کارت ویزیت نگه دارم | تب **گالری** → افزودن عکس |
| قفل بگذارم | **تنظیمات** → قفل برنامه (پین ۴ رقمی) |

## ۵. پشتیبان — این را جدی بگیر

داده‌ها **فقط روی گوشی خودت** هستند. اگر گوشی را گم کنی یا برنامه را پاک کنی، بدون پشتیبان چیزی برنمی‌گردد.

دو راه داری:

**الف) پشتیبان دستی (ساده و بدون حساب)**
**تنظیمات** → **داده و همگام‌سازی** → **پشتیبان کامل (با عکس)** → فایل ZIP را برای خودت بفرست (تلگرام، ایمیل، درایو). برای بازگرداندن: همان صفحه → **بازیابی از فایل**.

**ب) همگام‌سازی ابری (اختیاری)**
**تنظیمات** → **همگام‌سازی** → ساخت حساب با ایمیل و رمز (حداقل ۸ نویسه).
با همان ایمیل و رمز روی گوشی نو، داده‌ها برمی‌گردند.

> **توجه: رمز قابل بازیابی نیست.** نه ایمیل تأیید می‌شود نه «فراموشی رمز» وجود دارد. اگر رمز را فراموش کنی، پشتیبان ابری برای همیشه از دست می‌رود. رمز را جایی مطمئن نگه دار. اگر همگام‌سازی را روشن نکنی، هیچ‌چیز از گوشی بیرون نمی‌رود.

## ۶. حریم خصوصی، در یک پاراگراف

همهٔ داده‌ها روی گوشی خودت ذخیره می‌شوند و برنامه کامل آفلاین کار می‌کند. برنامه هیچ تحلیل‌گر، تبلیغ، یا ابزار ردیابی ندارد. اگر همگام‌سازی را خودت روشن کنی، داده‌ها روی سرور **رمزنگاری‌نشده** ذخیره می‌شوند — یعنی سرور (و کسی که به آن دسترسی دارد) می‌تواند آن‌ها را بخواند. برنامه همین را قبل از فعال‌سازی می‌گوید. اگر این برایت مهم است، همگام‌سازی را روشن نکن و فقط از پشتیبان دستی استفاده کن.

## ۷. اگر مشکلی پیش آمد

| مشکل | راه‌حل |
|---|---|
| «برنامه نصب نشد» | احتمالاً نسخهٔ قدیمی‌تری روی گوشی داری. اول نسخهٔ قبلی را حذف کن (پشتیبان بگیر!) |
| اعلان‌ها نمی‌آیند | **تنظیمات** → یادآوری را روشن کن و اجازهٔ اعلان اندروید را بده |
| عکس‌ها آپلود نمی‌شوند | در «حساب و پشتیبان» → «آپلود فایل‌ها» و اینترنت را بررسی کن |
| بعد از ریبوت یادآور نیامد | اپ را یک بار باز کن؛ زمان‌بندی دوباره ساخته می‌شود |
